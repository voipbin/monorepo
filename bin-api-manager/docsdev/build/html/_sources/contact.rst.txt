.. _contact-main:

**************
Contact
**************
Manage contacts with phone numbers, names, and tags for use in campaigns and call routing. Contacts serve as the address book for outbound operations and caller identification. Related sub-resources cover standalone address management, case management for tracking related interactions, and raw peer/activity event logs.

**API Reference:** `Contact endpoints <https://api.voipbin.net/redoc/#tag/Contact>`_, `Case endpoints <https://api.voipbin.net/redoc/#tag/Case>`_
