***************
Number Provider
***************
A number provider is a carrier that VoIPBin buys phone numbers from. The Number Provider API lets a platform administrator enable or disable a carrier, set the order in which carriers are tried when a number is purchased, and store the carrier credentials. It is not the SIP trunk :ref:`Provider <provider-main>` resource, which routes calls.

**API Reference:** `Number provider endpoints <https://api.voipbin.net/redoc/#tag/NumberProvider>`_
