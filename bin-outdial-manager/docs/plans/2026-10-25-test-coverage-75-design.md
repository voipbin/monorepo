## 2. Design (test plan)

New `_test.go` files, plus new functions in the existing `models/outdial/convert_test.go`; no product code, go.mod or go.sum change; names `Test_<Func>`, gomock controller `mc`, synthetic values only, no network, no shared mutable state except viper and the logrus level/formatter in `cmd/outdial-control` (every test of `resolveUUID`, `runCreate` and `initCommand` calls `viper.Reset()` at the start of each case and in `t.Cleanup`, because the keys persist across cases and `-count=3`; `initCommand` calls `config.Bootstrap`, which changes the global logrus formatter and level and binds viper; the test saves and restores both and calls `viper.Reset()` in `t.Cleanup`; these tests do not use `t.Parallel`). Assertions use `reflect.DeepEqual`/`t.Errorf` (no testify), as the conventions gate requires.

dbhandler helper constraints: `newMockHandler` hides its cache and util mocks and fixes `TimeGetCurTime`/`TimeNow` with `AnyTimes`, and its cache mock already answers the by-reference and by-activeflow lookups with a miss. Tests that need cache expectations (hit, miss, write failure, refresh failure after Create/Update/Delete via an exec expectation followed by a query error or an `OutdialSet` error, no call) replace `h.cache` with their own `MockCacheHandler`; the empty-token test verifies the bound value (`2026-01-01 00:00:00.000000`) with `WithArgs`, not the call count. "No SQL" is checked by sqlmock raising on an unexpected query plus `ExpectationsWereMet`; `*Update` sets `tm_update` before `PrepareFields`, which does not change that check.
