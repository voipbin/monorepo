## Test rules

`Test_` prefixed names, gomock controller named `mc`, fixed UUID strings, synthetic values only (`example.com`, `127.0.0.1`, fake keys), no outbound network, no secret literal next to an address in one literal. Global state rules:
- config and viper: set `config.Get().DatabaseDSN` explicitly to a refused loopback address (`127.0.0.1` with a closed port obtained by listen then close; never a non-routable address, which can hang) and restore it plus `viper.Reset()` in `t.Cleanup`; the `initCache` test likewise sets `config.Get().RedisAddress` to a refused loopback address (and clears `RedisPassword`) and restores both; `DATABASE_DSN` from the environment is overridden the same way.
- `initProm`: the enabled branch registers on `http.DefaultServeMux` and panics on a duplicate pattern, so the test guards it with `sync.Once` (a `-count=N` rerun skips the second call) and uses a loopback free port; the serving goroutine is left running. The mutation check for the disabled branch runs in a scratch copy only.
- No `t.Parallel()` in `cmd` tests. `printJSON` output is captured by swapping `os.Stdout` and restoring it in `t.Cleanup`. `initCommand` calls `config.Bootstrap`, which sets the logrus formatter and level; the test restores both in `t.Cleanup`.
- `runService`/`initSignal` are not called (process-wide `signal.Notify` and a goroutine that would compete for `chSigs`); `signalHandler` is called directly.
- `runListen` returns nil even when `Run` fails, so the error case asserts nil plus the mock expectations.
- signals: `signalHandler` is tested by sending to `chSigs` and receiving from `chDone`; no real signal is sent. `initSignal` is not called (it registers process-wide notification and a goroutine).
- `runListen`: `ConsumeRPC` runs in a goroutine from `Run`, so the mock expectation signals a channel and the test waits for it before finishing.
- Only loopback httptest servers are used for `download`. The sendgrid header-less response test replaces `sendgrid.DefaultClient`'s transport only, restores it in `t.Cleanup` (copy the client value and swap `HTTPClient`; do not import `github.com/sendgrid/rest`, which is an indirect dependency and would change `go.mod`), sets `BaseURL` to a loopback address and asserts its hostname, and never uses a real key or host; no test in this PR may reach a network address other than loopback.
- The logrus test hook used by the `initProm` occupied-port test is removed (`hook` reset) in `t.Cleanup`, and the log assertion polls with a timeout.
- Injection tests (global `sendgrid.DefaultClient`, `os.Stdout`, viper, config, logrus) never use `t.Parallel()`.
